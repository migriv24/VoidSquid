**Claim this bundle leans on.** **Procedural rhetoric** is *"the practice of persuading
through processes."* A game's thesis is in its mechanics: which actions earn, which
cost, which are impossible. Bogost's worked examples are political and advertising
games, where the rules carry the message whatever the text says.

**What it settles here.** The author: upgrades *"carry themes and messages of the world
itself. Because its the game saying 'this is what it means to be BETTER.'"* That is
Bogost's claim applied to progression. It has a design consequence that
[what a game is](/concepts/what-a-game-is.md) §4 adopts: **the upgrade graph is where the
game's values are written**, so it is authored structure (links of kind `unlocks`,
`requires`, `costs`), queryable in the forge, and the first thing a
[deconstruction](/concepts/construct-and-deconstruct.md) of an existing game should
recover. [Hocking](/sources/hocking-ludonarrative-dissonance.md) names what happens when
the upgrade graph and the story disagree.
