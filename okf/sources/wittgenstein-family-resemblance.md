**Claim this bundle leans on.** Asked what all games have in common, Wittgenstein answers:
look and see; you will find *"a complicated network of similarities overlapping and
criss-crossing,"* and he names it **family resemblance**. Board games, card games, ball
games, ring-a-ring-a-roses: some are competitive, some are not; some are skill, some luck;
some are amusing, some are not. No necessary-and-sufficient definition survives.

**What it settles here.** [What a game is](/concepts/what-a-game-is.md) does not try to
define a game. It states what *Void Squid's* games must have (the author's five beliefs)
and keeps the vocabulary **extensible** so that a game outside that set, Tetris for one,
can still be *described* when it arrives through
[deconstruction](/concepts/construct-and-deconstruct.md). Void Core's glyphs and
axis-typed tags are an open vocabulary by construction, which is why the model is a
vocabulary and not a schema.
